# Humor HQ

The protected administration app for the existing **Humor Project** Supabase database is in [humor-admin](./humor-admin).

```sh
cd humor-admin
npm ci
npm run dev
```

Open the local URL printed by the dev server. Sign in with the Google account assigned a superadmin role in the database.

See [the app README](./humor-admin/README.md) for routes, permissions, database setup, and validation.
